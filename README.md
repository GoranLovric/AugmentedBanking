# AugmentedBanking
Accompanying documentation for the paper Aigner Simon and Lovric Goran: "Integrating LLMs into R Shiny-based Risk Management Applications" 


In this case study, we present a straightforward example demonstrating how a large language model (LLM) can be integrated into an R Shiny-based
environment. The study illustrates not only the technical connection of the LLM to the interactive application, but also how the skillset provided en-
ables the application to move beyond conventional chatbot tasks. Specifically, the system is empowered to autonomously execute user-specified ac-
tions in real time. As a practical demonstration, we have developed an email-agent capable of composing emails based on user prompts, attaching
relevant documents, and generating messages that adhere to a predefined design, performed automatically within the R Shiny interface. This showcases
the potential of agentic AI systems to seamlessly blend natural language understanding with direct task execution in applied settings.
